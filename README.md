# API Tests for The Metropolitan Museum of Art

Набор автоматизированных тестов для публичного API Музея Метрополитен
(https://metmuseum.github.io). Проект демонстрирует валидацию ответов
через Pydantic и тестирование REST API с помощью pytest.

## Стек

- Python 3.11+
- pytest — тестовый фреймворк
- httpx — HTTP-клиент
- Pydantic — валидация данных

## Запуск тестов

        pytest

## Что проверяют тесты

- Получение произведения искусства по ID (статус 200 и валидация).
- Обработка несуществующего ID (статус 404).
- Поиск по ключевому слову с валидацией структуры ответа.
- Фильтрация: `departmentId`, `isHighlight`, `hasImages`.
- Ограничение количества результатов (`limit`).
- Пагинация (`offset`).
- Отключение старого эндпоинта `/search` (статус 410).
- Соблюдение rate limit (80 запросов/сек).
